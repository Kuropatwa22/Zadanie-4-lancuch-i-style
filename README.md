# Zadanie 4 — łańcuch i style

Zrobiłem trzy przyciski na dole ekranu w ConstraintLayout.

Sprawdziłem trzy style łańcucha:

 **spread** — przyciski są rozłożone z odstępami między nimi i krawędziami ekranu.
 **spread_inside** — pierwszy i ostatni przycisk są przy krawędziach, a odstępy są pomiędzy przyciskami.
**packed** — przyciski są blisko siebie na środku.

Na końcu zostawiłem styl **spread** i wagi **1 : 2 : 1**.

Dzięki wagom środkowy przycisk jest dwa razy szerszy od pozostałych.
